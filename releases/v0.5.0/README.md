# v0.5.0

- 修复 `runtime-context` 等模型上下文被当作普通用户消息展示。按消息来源过滤，用户主动引用相同文字仍正常显示。
- 配对信息长期保存；Android 继续使用 Keystore 加密，浏览器/iOS 共用代码使用 IndexedDB 中的非导出密钥与 AES-GCM 密文。临时网络故障或主机离线不清除配对。
- 新增应用心跳、网络恢复和回到前台自动重连；任务继续在电脑执行。电脑仍须保持开机、联网并运行 DSH。
- 点击输入框下方的模型名称进入「模型与推理」，选择 DSH 实际提供的推理档位；不支持的模型有明确提示。
- 「+」支持图片与普通文件，发送前可预览、移除，失败保留草稿和附件；每次最多 6 个附件、合计 4 MB。需要电脑端插件 **v0.4.0**。

安装本目录 APK 可覆盖更新同签名旧版本；签名与 v0.4.0 一致。不要卸载旧 App，以保留配对。

验证：18 项逻辑测试、17 项手机界面流程，以及 DSH 0.2.1-rc.5 真实 LAN/WSS 测试。真实测试覆盖图片入库与历史预览、文件上传与跨会话凭据拒绝、推理强度保存及心跳；模型仅用隔离本地回显，无外部模型请求。未连接实体 USB 手机，未进行 iOS 原生构建。

交互参考：[OpenAI 官方远程连接说明](https://learn.chatgpt.com/docs/remote-connections)。
