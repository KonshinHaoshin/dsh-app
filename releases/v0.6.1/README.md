# v0.6.1

减少首屏及多电脑场景的同步开销：

- 最近消息从 100 条改为 30 条，更早消息仍可手动加载。
- 未选中电脑保留审批连接，暂停聊天记录、工作区订阅，切回时恢复最新快照；模型目录在本次连接中复用。
- 密集事件合并刷新会话列表，避免并发列表请求和旧连接数据覆盖。
- 流式输出复用历史消息解析结果。

19 项逻辑测试、20 项界面测试及 Android APK 构建通过。新增回归验证后台电脑不订阅记录、审批仍可收到、切回后显示后台回复，以及 100 个状态事件合并为一次列表刷新。尚未在手机真机测量载入耗时；未实现 P2P，弹窗报告仍待复现。

沿用原签名，可直接覆盖 v0.6.0，配对、后台连接和通知设置保留。无需更换中继密钥或更新电脑插件。
