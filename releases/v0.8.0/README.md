# v0.8.0

- 对话页隐藏 write / edit / pwsh 等工具调用卡片，完整详情保留在「执行记录」。
- 近期会话与列表加密缓存，先显示历史预览，再同步电脑端最新快照；不会重发指令。缓存有效期 7 天，总量最多 8 MiB，移除电脑时清除。
- 首次配对引导开启 Android 后台通知；已授权连接在启动、恢复及切回桌面时由原生代码检查并恢复，不依赖 WebView。明确关闭后保持关闭。
- 后台审批订阅按电脑核对，新增服务状态、系统退出原因诊断及红米 / 小米自启动、省电策略入口。
- 保留 P2P 直连、自动中继回退、任务结束与手动审批通知，电脑插件无需升级。

覆盖安装此 APK，或在 App 的「连接 → 检查更新」安装。保留原 App 以保留配对。红米 K70 建议在「后台连接与通知」开启服务、允许通知和自启动，并将省电策略设为“无限制”。厂商系统清理和系统强制停止仍可能中断服务；本版未在 K70 实机验证。

验证：22 项逻辑测试、23 项界面回归通过；Android 17 空白隔离模拟器验证 Keystore 缓存加密、过期和移除，暂停 WebView 后按 Home 恢复停止的服务，锁屏强制 Doze 下任务 / 审批通知、显式审批、原生重连及保留关闭选择。真实公网信令 / STUN 建立原生 P2P，暂停 WebView 并锁屏休眠后仍接收通知，切断直连后回退中继、保留审批并只手动回复一次。使用模拟 DSH，不调用模型或执行工具；不代表验证了所有厂商系统或异地网络。
