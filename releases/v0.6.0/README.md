# v0.6.0

Android 后台连接与通知：

- 「连接 → 后台连接与通知」主动开启原生前台服务，默认关闭；通知栏有连接状态和关闭操作。
- 切后台、锁屏后继续接收任务结束和审批提醒；通知默认隐藏具体命令，打开后回到对应电脑和会话。
- 审批由独立原生通道维护，界面不会重复注册同一审批接收器；仅手动确认后回复，不自动允许操作。
- 支持断线重连和多个电脑。需要允许系统通知；长时间锁屏建议允许电池不受限制，会增加耗电。强行停止应用、关机或电脑离线时不能保证实时接收。

检查更新：

- 入口位于连接页顶部；Android 启动和回前台每天自动检查一次，保留发现的新版本提示。
- App 内显示 APK 下载进度，校验大小、SHA-256、包名、版本和与已安装应用一致的签名。
- 下载后通过系统安装界面确认更新，首次需允许 DSH 安装应用；不会静默安装。
- 覆盖更新保留配对，不要卸载旧 App。安装完成后重新打开 App。

验证：19 项逻辑测试、18 项手机界面测试通过；原生代码编译成功。在独立 Android 17 模拟器中，授予电池豁免后锁屏并强制 Doze、暂停 WebView JavaScript，验证原生任务/审批通知、通知意图导航、显式审批回复、原生重连与非法更新源拒绝。协议测试使用本机模拟服务，不调用模型或执行命令。

本次无需更换中继密钥或更新电脑插件。iOS 暂未实现后台通知或提供签名包。
